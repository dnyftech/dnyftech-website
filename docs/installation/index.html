Installation

The website is a static HTML, CSS, and JavaScript project. Clone the repository and serve the project root with any local static web server.

git clone https://github.com/dnyftech/dnyftech-website.git
cd dnyftech-website

Open index.html or serve the directory with a local static server. The project does not require a package installation for these static pages.
